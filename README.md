# 🚀 Excelerate User Engagement Dashboard ### *Transforming Data into Actionable Insights*[cite: 4] []() []() []()
--- ## 👥 Meet the Team | Role | Team Member | | :--- | :--- | | **Team Lead** | Abhay Sahu[cite: 4] | | **Members** | Abdullah Zafar, Alimot Ola, Kalyani Kondepu[cite: 4] | --- ## 🌟 Executive Summary The **Excelerate User Engagement Dashboard** is a powerful, real-time analytics platform designed to monitor web traffic, user behavior, demographics, and program performance[cite: 3, 4]. By converting raw user logs into a modular reporting grid[cite: 1], this tool empowers platform leadership to optimize marketing strategies, identify high-demand skills, and drive data-backed decision-making[cite: 4]. --- ## ✨ Core Dashboard Modules * 📊 **Platform Activity & KPIs**: Tracks high-level milestones, including **27.4K** overall sign-ups and **20.3K** active opportunity registrations[cite: 3]. * 🌍 **Global & Regional Reach**: Interactive global maps and rankings highlighting international adoption—led by India, the United States, and Nigeria[cite: 3]. * 🔻 **Opportunity Popularity Funnel**: Visualizes user progression from general interest to specific category enrollments, showing peak engagement in *Data Visualization* and *Project Management*[cite: 3]. * 🎓 **Demographics & Student Status**: Breaks down user profiles by gender distribution and academic milestones (ranging from graduate students to high schoolers)[cite: 3]. * 💰 **Scholarship Distribution**: Analyzes capital allocation across opportunity categories, highlighting major investments in data science and AI/ML tracks[cite: 3]. * ⚙️ **Dynamic Filtering**: Features real-time filters for date ranges, countries, U.S. states, and user statuses to allow seamless drill-down analysis[cite: 4]. --- ## 🛠️ Tech Stack & Methodology * **Data Wrangling**: Python (`pandas`, `numpy`) used for data cleaning, handling missing values, standardizing zip/city formats, and exporting to `NewUserData.csv` and `NewOpportunityDataset.csv`[cite: 1]. * **Visualization Engine**: Google Looker Studio (formerly Data Studio) for interactive real-time reporting[cite: 4]. * **Design Framework**: Modular wireframing mapped out to prioritize scannability and executive-level visibility[cite: 1]. --- ## 📈 Key Insights & Strategic Takeaways * **Conversion Optimization**: While platform sign-ups reach **27.4K**, opportunity participation sits at **20.3K**, indicating a need for targeted onboarding and retention campaigns[cite: 3]. * **Geographic Hubs**: High adoption clusters in key metropolitan areas like New York, Los Angeles, and Chicago, as well as international hubs in India and Nigeria[cite: 3, 5]. * **In-Demand Skills**: Technical capabilities like Python Programming, Data Analysis, and Machine Learning drive the highest engagement and completion rates[cite: 5]. ---
